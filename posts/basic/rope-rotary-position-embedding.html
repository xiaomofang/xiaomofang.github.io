RoPE 旋转位置编码：
从二维旋转到相对位置与长上下文

给每个位置一个旋转角度，为什么两个向量的点积就能读出相对距离？RoPE 的关键是让「位置相减」成为旋转矩阵相乘的自然结果。本文沿着苏剑林在科学空间原文与 RoFormer 原论文所讨论的问题，从几何、代数一路走到实现与长度外推。

RoPE · 位置编码 PyTorch 训练

2026年9月18日 · 50 分钟 · MOFANG

一、位置编码要解决的，到底是什么问题

1.1 内容相似，不等于关系相同

「小猫追小狗」和「小狗追小猫」包含相同的词，关系却相反。对一个单独的 query 而言，如果 key/value 成对换序，而没有位置编码或相应掩码提供额外结构，注意力的加权结果不会因此改变。更一般地，无位置编码的全连接 self-attention 对输入置换是等变的：输入换序，输出也跟着换序。

因果掩码会打破这种任意置换对称性，但它直接规定的是「哪些位置可见」，并没有显式告诉点积「相隔一个词」与「相隔一百个词」该如何区别。位置编码要做的，就是为内容匹配提供这样的坐标结构。

\[ q_m=W_Qx_m,\quad k_n=W_Kx_n,\quad s_{m,n}=\frac{q_m^{\mathsf T}k_n}{\sqrt{d}}. \]

下文把向量写成列向量，位置从 0 开始，\(d\) 表示一个 attention head 的维度。\(q_m,k_n\) 是当前层尚未应用 RoPE 的表示；它们可能已经通过前面的层包含上下文信息。「没有应用本层旋转」不意味着它们完全没有位置信息。

1.2 从加法位置编码走向相对位置

绝对位置编码通常把 \(p_m\) 加到输入上。暂时省略投影，展开点积就能看到内容与位置怎样混合：

\[ (x_m+p_m)^{\mathsf T}(x_n+p_n) =x_m^{\mathsf T}x_n+x_m^{\mathsf T}p_n +p_m^{\mathsf T}x_n+p_m^{\mathsf T}p_n. \]

正弦位置向量之间的点积可以具有相对位移结构，但加入内容交叉项与一般的可学习投影后，整个分数并不自动只通过距离依赖位置。RoPE 换了一个设计目标：能否分别处理 query 和 key，同时保证它们比较时的位置因子只依赖 \(n-m\)？

目标：用绝对位置执行变换，用相对位置控制匹配。这不是要求分数只取决于距离；内容仍然决定相关性。要求的是，固定内容向量后，显式位置依赖可以合并成一个相对位移。

二、二维旋转：把位置差写进点积

2.1 为什么角度要随位置线性增长

先考虑一个二维平面。把 query 转过 \(\phi(m)\)，key 转过 \(\phi(n)\)，它们的夹角变化就是 \(\phi(n)-\phi(m)\)。若希望这个变化只取决于位置差，那么相隔一步的角度差必须处处一样：

\[ \phi(m+1)-\phi(m)=\theta \quad\Longrightarrow\quad \phi(m)=m\theta+\phi(0). \]

把位置 0 设为不旋转，即 \(\phi(0)=0\)，就得到 \(m\theta\)。这里 \(\theta\) 是每前进一步转过的弧度。这个推导是在「用平面旋转编码位置」的假设下进行的，角度按模 \(2\pi\) 理解；它没有声称所有位置编码都只能采用 RoPE。

2.2 核心恒等式，逐步推一遍

二维逆时针旋转矩阵为：

\[ R(\alpha)=\begin{pmatrix} \cos\alpha&-\sin\alpha\\ \sin\alpha&\cos\alpha \end{pmatrix}. \]

旋转不改变长度，因此 \(R(\alpha)^{\mathsf T}=R(-\alpha)\)；连续旋转则把角度相加，因此 \(R(\alpha)R(\beta)=R(\alpha+\beta)\)。定义 \(\tilde q_m=R(m\theta)q_m\)、\(\tilde k_n=R(n\theta)k_n\)，于是：

\[ \begin{aligned} \tilde q_m^{\mathsf T}\tilde k_n &=q_m^{\mathsf T}R(m\theta)^{\mathsf T}R(n\theta)k_n\\ &=q_m^{\mathsf T}R(-m\theta+n\theta)k_n\\ &=\boxed{q_m^{\mathsf T}R((n-m)\theta)k_n}. \end{aligned} \]

这就是 RoPE 的核心。位置在 Q/K 两侧分别进入，点积却把它们合并成差值。若同时把两者位置平移 \(c\)，就有 \((n+c)-(m+c)=n-m\)，所以在内容向量不变的前提下分数不变。

旋转保长度，为何还能改变注意力？保长度只意味着每个向量的模不变。两个向量转过不同角度时，夹角会变，点积自然会变；只有它们经历同一个旋转时，点积才保持不变。

2.4 复数只是同一件事的紧凑写法

把二维向量 \((a,b)\) 对应为复数 \(z=a+ib\)，乘以 \(e^{i\alpha}\) 就是在平面上旋转。利用实向量点积等于复数共轭乘积的实部：

\[ \operatorname{Re}\!\left[ \overline{z_qe^{im\theta}}\,z_ke^{in\theta} \right] =\operatorname{Re}\!\left[ \overline{z_q}z_ke^{i(n-m)\theta}\right]. \]

某些资料使用 \(z_q\overline{z_k}\)，对应指数写成 \(m-n\)；两式互为共轭，实部相同。真正需要检查的是共轭对象、旋转方向与位置差的符号是否一致。复数为什么不丢信息、共轭与实部为什么缺一不可，见附录 A的完整展开。

三、高维 RoPE：许多个不同转速的二维平面

3.1 每两个通道组成一个旋转平面

一个 head 通常有几十到几百维。对偶数维 \(d\)，将相邻通道配对为 \((0,1),(2,3),\ldots\)，每一对使用一个频率：

\[ \theta_j=b^{-2j/d},\qquad j=0,\ldots,d/2-1, \qquad b=10000\ \text{（原论文设置）}. \]
\[ R_m=\operatorname{diag}\!\bigl(R(m\theta_0),\ldots,R(m\theta_{d/2-1})\bigr), \qquad R_m^{\mathsf T}R_n=R_{n-m}. \]

内积等于各二维子空间内积之和，所以二维结论直接推广到高维。注意公式分母是参与旋转的维度；全维 RoPE 时它就是 head dimension，不能随手替换为整个模型的 hidden size。

3.2 手算例子：四维向量里的快、慢时钟

取 \(d=4,b=10000\)，则 \(\theta_0=1\)、\(\theta_1=0.01\)。同样前进一个位置，第一对通道转 1 弧度，第二对只转 0.01 弧度。对 \(q=k=(1,0,1,0)^{\mathsf T}\)，记 \(\Delta=n-m\)，未缩放的匹配分数为：

\[ S(\Delta)=\cos\Delta+\cos(0.01\Delta). \]

高频对相邻位置更敏感，低频在更长范围内缓慢改变相位。一个二维平面的周期是 \(2\pi/\theta_j\)；在这个例子里，两个周期约为 6.28 和 628.32 个位置。多频率共同提供多尺度描述，模型通过 Q/K 的内容分量学习如何使用它们。

10000 是频率设计的超参数。相对位置恒等式对任何固定且 Q/K 一致的频率组都成立。几何级数频率提供多尺度结构，但这个具体底数不是由恒等式唯一推出来的。

四、「远程衰减」不能理解成距离越远分数越小

4.1 相位抵消提供趋势，内容决定实际分数

上一张表已经给出反例：距离从 3 增至 6，分数反而大幅回升。单个频率是周期函数；有限个周期分量叠加，也不可能保证所有 query/key 的分数都随距离单调下降。

把每一组的内容系数写开，令 \(\Delta=n-m\)，有：

\[ S(\Delta)=\sum_j\left[A_j\cos(\Delta\theta_j)+B_j\sin(\Delta\theta_j)\right], \]
\[ A_j=q_{2j}k_{2j}+q_{2j+1}k_{2j+1},\qquad B_j=q_{2j+1}k_{2j}-q_{2j}k_{2j+1}. \]

距离改变的是相位；内容改变的是每个频率的系数。不同频率随距离增长会出现相位错开与抵消，这为远近关系提供一种偏置，但不能替代模型学到的语义匹配。

4.2 原论文的衰减图究竟画了什么

原论文 §3.4.3 使用 Abel 变换，把复数系数加权和的绝对值上界与频率部分和联系起来。设 \(D=d/2\)、\(h_j=\overline{z_{q,j}}z_{k,j}\)，并补上 \(h_D=0\)。定义 \(P_r(\Delta)=\sum_{j=0}^{r-1}e^{i\Delta\theta_j}\)，则：

\[ \left|\sum_{j=0}^{D-1}h_je^{i\Delta\theta_j}\right| \le\max_{0\le j<D}|h_{j+1}-h_j| \sum_{r=1}^{D}|P_r(\Delta)|. \]

Figure 2 展示的是这个推导中与频率有关的平均部分和模长 \(D^{-1}\sum_r|P_r(\Delta)|\) 的数值趋势。它不是某个模型的 attention 权重曲线，也不是任意内容向量都严格单调衰减的证明；内容系数的变化幅度仍然出现在上界中。这个上界如何从前缀和得到，见附录 B。

分清三个对象。旋转后的点积是匹配分数；原论文画的是分析上界中的频率量；softmax 输出才是归一化后的注意力权重。分数可能为负，权重还取决于同一行其他 key 的竞争。

五、PyTorch 实现：公式如何落到 Tensor

5.1 只需要逐元素乘法，不需要构造大矩阵

对一对通道 \((a,b)\)，旋转结果是 \((a\cos\alpha-b\sin\alpha,\ a\sin\alpha+b\cos\alpha)\)。因此只需保存 sin/cos 并逐对计算，额外计算量随 token 数和通道数线性增长。

下面使用相邻通道配对，输入形状为 [batch, heads, seq, dim]，位置为 [batch, seq]。该函数分别用于 Q 与 K，因此二者的 head 数可以不同，能够容纳 GQA。这里实现全维、固定频率的基础版本。

import torch

def apply_rope(x, position_ids, base=10000.0):
    # x: [B, H, T, D], position_ids: [B, T]
    batch, _, seq, dim = x.shape
    if dim % 2:
        raise ValueError("RoPE requires an even rotary dimension")
    if position_ids.shape != (batch, seq):
        raise ValueError("position_ids must have shape [B, T]")

    # Keep phase computation in FP32 even under mixed precision.
    with torch.autocast(device_type=x.device.type, enabled=False):
        inv_freq = base ** (
            -torch.arange(0, dim, 2, device=x.device,
                          dtype=torch.float32) / dim
        )
        positions = position_ids.to(device=x.device, dtype=torch.float32)
        angles = positions[..., None] * inv_freq  # [B, T, D/2]
        cos = angles.cos()[:, None, :, :]         # [B, 1, T, D/2]
        sin = angles.sin()[:, None, :, :]
        even = x[..., 0::2].float()
        odd = x[..., 1::2].float()
        rotated = torch.stack(
            (even * cos - odd * sin, even * sin + odd * cos),
            dim=-1,
        ).flatten(-2)
    return rotated.to(x.dtype)

# Q/K projection and head reshape have already happened.
# q_rot = apply_rope(q, position_ids)
# k_rot = apply_rope(k, position_ids)
# Pass q_rot, k_rot and v to the attention kernel.

这里有意用 FP32 算角度和三角函数，再转回输入类型。低精度位置乘法在较长序列上容易丢失相位精度。生产实现通常复用频率表、预计算或缓存 sin/cos，并融合旋转与 cache 写入，避免中间 Tensor 带来的开销。

5.2 相邻配对与前后半维配对

阅读模型源码时，常会碰到 rotate_half：把前半维与后半维配对，而不是把相邻两维配对。

布局（d = 8）配对频率展开
相邻配对(0,1), (2,3), (4,5), (6,7)每个频率连续重复两次
前后半维配对(0,4), (1,5), (2,6), (3,7)整组频率复制两份

这两种布局可通过一致的通道置换联系起来，但对于一个固定 checkpoint，不能只换旋转代码。Q/K 投影输出的通道次序、频率展开与旋转实现必须一起对应；否则公式看似一样，实际匹配的坐标已经变了。

V 通常不旋转。标准 LLM RoPE 用 Q/K 的相对旋转改变「从哪里读」，V 提供被读取的内容。旋转 V 是另一种模型设计，不是得到相对位置点积的必要步骤。RoPE 也不负责实现因果掩码。

5.3 KV cache：位置编号必须保持连续

在通常缓存已旋转 K 的实现中，prefill 先为位置 0 到 \(T-1\) 生成旋转后的 key，随后写入 cache。decode 的新 token 使用位置 \(T\) 旋转自己的 Q/K，再与历史 K 比较。历史 K 不需要每一步重新旋转。

如果 decode 每次把新 token 的位置重置为 0，它与历史 key 的相对角度就错了。左侧 padding、分块 prefill、滑动窗口以及前缀复用都需要区分「缓存中的物理槽位」与「模型的位置编号」。在固定频率下，若要整体变更位置原点，也必须对 Q/K 保持一致，不能只改新 query。

RoPE 与 KV 压缩是不同层面的问题。GQA 改变 KV head 的共享方式，RoPE 改变 Q/K 的位置几何；MLA 则还需要处理位置相关旋转对投影吸收的影响。可以继续阅读本站的MHA → MQA → GQA → MLA，把位置编码接回缓存结构。

六、能计算更大的位置，不等于能理解更长的文本

6.1 数学定义没有查表上限，训练分布仍有边界

学习式绝对位置表若只有有限行，超出范围就没有对应参数。RoPE 的 sin/cos 可以在更大的位置求值，从形式上避开了这一限制。然而，模型是在有限距离、有限相位组合和有限长度的注意力竞争中训练的；序列变长后，这些分布都会变化。

尤其是训练窗口里变化很慢的低频通道，可能从未走过完整周期。把位置直接拉长，就可能让模型遇到未学习过的角度区间。高频虽然见过周期，也会在更远距离重复相位，单个通道不足以区分全部距离。多频率缓解了歧义，却没有给出任意长度泛化的保证。

6.2 插值与改底数，分别改变什么

最容易理解的位置插值（Position Interpolation）把目标位置压回较短的坐标范围。若扩展倍率为 \(s\)，采用：

\[ m'=m/s,\qquad \alpha_j(m)=m\theta_j/s. \]

新窗口里的最大角度被压低，但相邻 token 的角度差也从 \(\theta_j\) 变为 \(\theta_j/s\)。因此它在扩大覆盖范围的同时改变了局部距离分辨率，通常需要相应微调与任务评估。

策略位置相位如何变化要验证的代价
直接外推继续使用原位置与原频率未见过的相位组合与长距离分布
位置插值所有频率统一缩小为原来的 1/s短距离分辨率改变，通常需要微调
增大 RoPE base除第 0 组外，各组频率按不同幅度降低频谱改变，需要匹配训练与模型配置
YaRN 等扩展方法按频段调整，并结合注意力缩放等设计不能只替换一个常数就假定复现论文效果

增大底数与统一插值不是一回事：\(\theta_0=b^0=1\) 始终不变，而后面的频率才随底数变化。固定频率重标定仍保留相对旋转恒等式；如果服务过程中动态改变频率，还要保证缓存中的旧 K 与新 Q 使用兼容的频率体系。

上下文窗口是一项端到端能力。除了位置相位，还要检查长文本检索与推理质量、训练长度覆盖、KV 容量和注意力计算成本。RoPE 本身不会把标准 attention 的二次计算量变成线性；FlashAttention解决的是另一层面的 IO 与中间存储问题。

附录 A：从复数基础到 f、g 的相对位置恒等式

这一附录补齐第二章省略的代数步骤，也对应常见 RoPE 介绍中从二维复数表达推到旋转矩阵的过程。为避免与外部资料的公式（8）～（11）混淆，附录单独使用 A、B 编号。先在二维证明，再推广到整个 attention head；不要求读者预先掌握复数内积。

推导顺序。列向量与 QKᵀ → 复数与旋转 → 定义 f 与 g → 证明点积等于 g → 推广到多频率 → Abel 变换与上界。

A.1 先统一记号：为什么单个点积是 qᵀk，代码却是 QKᵀ

本文采用线性代数中常见的列向量约定，这是作者选定的表示方式，不是 Query 必须遵守的行业规则。取 \(x_m\in\mathbb R^{d_{\mathrm{model}}}\)、\(W_Q\in\mathbb R^{d\times d_{\mathrm{model}}}\)，则 \(q_m=W_Qx_m\in\mathbb R^d\)。先不考虑 batch 和 head 的前导维度。

\[ q_m=\begin{pmatrix}q_{m,0}\\q_{m,1}\\\vdots\\q_{m,d-1}\end{pmatrix},\quad Q=\begin{pmatrix}q_0^{\mathsf T}\\q_1^{\mathsf T}\\\vdots\\q_{L_q-1}^{\mathsf T}\end{pmatrix},\quad K^{\mathsf T}=\begin{pmatrix}k_0&k_1&\cdots&k_{L_k-1}\end{pmatrix}. \tag{A1} \]

大写 Q 把每个 token 的向量按行排列，所以它的第 m 行本来就是 \(q_m^{\mathsf T}\)；对大写 K 转置后，第 n 列是 \(k_n\)。转置符号没有从 K「移到」q 上，只是两个层次的记号。

\[ \underbrace{Q}_{L_q\times d}\underbrace{K^{\mathsf T}}_{d\times L_k} \in\mathbb R^{L_q\times L_k},\qquad (QK^{\mathsf T})_{m,n}=q_m^{\mathsf T}k_n =\sum_{t=0}^{d-1}q_{m,t}k_{n,t}.\tag{A2} \]
对象形状计算含义
单个列向量 q、k(d, 1)qᵀk 得到一个标量
按行排列的 Q、K(Lq, d)、(Lk, d)QKᵀ 一次得到所有位置对的分数
NumPy 一维数组(d,)没有行列方向；q.T 仍为 (d,)，q[:, None] 才是列向量

这里的 d 是参与旋转的 head 维度。hidden_size 通常就是模型主干的 \(d_{\mathrm{model}}\)；标准多头设计常有 \(d_{\mathrm{model}}=H d\)，但注意力内部投影宽度也可以另行设计，GQA 的 KV 头数还可能少于 Query 头数。不要仅根据参数名称假定所有维度相等。记号 \(R_{\Theta,m}^{d}\) 中的上标 d 表示矩阵维度，不是 d 次幂。

A.2 两个实数如何变成复数：信息不变，运算规则必须对应

令虚数单位为 \(\mathrm{i}\)，满足 \(\mathrm{i}^2=-1\)。定义实平面到复平面的对应 \(\mathcal C\)：

\[ \mathcal C\!\left(\begin{pmatrix}a\\b\end{pmatrix}\right)=a+\mathrm{i}b, \qquad \mathcal C^{-1}(z)=\begin{pmatrix}\operatorname{Re}z\\\operatorname{Im}z\end{pmatrix}. \tag{A3} \]

实部保存 a，虚部保存 b，可以完整还原。这是 \(\mathbb R^2\) 与 \(\mathbb C\) 作为实向量空间的对应，并不表示任意实数矩阵运算都能原封不动替换成复数乘法。RoPE 恰好用到了其中与平面旋转一致的一种运算。

欧拉公式把指数函数与圆周上的坐标联系起来，角度使用弧度：

\[ e^{\mathrm{i}\alpha}=\cos\alpha+\mathrm{i}\sin\alpha, \qquad |e^{\mathrm{i}\alpha}|=\sqrt{\cos^2\alpha+\sin^2\alpha}=1. \tag{A4} \]

如果希望看到它从哪里来，可以展开指数函数的幂级数：偶数次幂形成余弦，奇数次幂形成正弦。以下级数对任意实数角度都收敛：

\[ \begin{aligned} e^{\mathrm{i}\alpha} &=1+\mathrm{i}\alpha+\frac{(\mathrm{i}\alpha)^2}{2!}+\frac{(\mathrm{i}\alpha)^3}{3!}+\cdots\\ &=\left(1-\frac{\alpha^2}{2!}+\frac{\alpha^4}{4!}-\cdots\right) +\mathrm{i}\left(\alpha-\frac{\alpha^3}{3!}+\frac{\alpha^5}{5!}-\cdots\right)\\ &=\cos\alpha+\mathrm{i}\sin\alpha. \end{aligned} \]

现在让 \(z=a+\mathrm{i}b\) 乘这个单位复数。把四项全部写出来：

\[ \begin{aligned} ze^{\mathrm{i}\alpha} &=(a+\mathrm{i}b)(\cos\alpha+\mathrm{i}\sin\alpha)\\ &=a\cos\alpha+\mathrm{i}a\sin\alpha+\mathrm{i}b\cos\alpha+\mathrm{i}^2b\sin\alpha\\ &=(a\cos\alpha-b\sin\alpha)+\mathrm{i}(a\sin\alpha+b\cos\alpha). \end{aligned}\tag{A5} \]

取出实部和虚部，重新排列成列向量：

\[ \mathcal C^{-1}(ze^{\mathrm{i}\alpha}) =\begin{pmatrix}a\cos\alpha-b\sin\alpha\\a\sin\alpha+b\cos\alpha\end{pmatrix} =\underbrace{\begin{pmatrix}\cos\alpha&-\sin\alpha\\\sin\alpha&\cos\alpha\end{pmatrix}}_{R(\alpha)} \begin{pmatrix}a\\b\end{pmatrix}.\tag{A6} \]

这就是「旋转」的来源。比如 \((1,0)\) 乘 \(e^{\mathrm{i}\pi/2}=\mathrm{i}\)，变成 \((0,1)\)：向右的箭头转到向上。乘数的模为 1，所以长度保持不变；乘 \(e^{-\mathrm{i}\alpha}\) 可以逆转回原向量。

复数表示不改变数据，旋转会改变坐标。从 (a,b) 改记为 a+ib 是无损换记号；再乘单位复数才是在执行 RoPE。实际实现既可以使用复数 Tensor，也可以用两组实数乘加。本文代码采用后一种，旋转后的 Q/K 与最终注意力分数仍然是实数。

A.3 为什么共轭与取实部缺一不可

取两组实数 \(q=(a,b)^{\mathsf T}\)、\(k=(c,e)^{\mathsf T}\)，分别对应 \(z_q=a+\mathrm{i}b\)、\(z_k=c+\mathrm{i}e\)。共轭就是把虚部反号，星号与横线是常见的两种写法：

\[ z_k^*=\overline{z_k}=c-\mathrm{i}e,\qquad z_q\overline{z_k}=(ac+be)+\mathrm{i}(bc-ae). \]
\[ \boxed{q^{\mathsf T}k=ac+be=\operatorname{Re}(z_q\overline{z_k})}. \tag{A7} \]

不取共轭时，乘积的实部是 \(ac-be\)，不是原来的点积；只取共轭而不取实部，结果还包含 \(bc-ae\) 这个虚部，同样不等于实数点积。比如 \((1+2\mathrm{i})(3-4\mathrm{i})=11+2\mathrm{i}\)，原向量点积恰好是实部 11。

A.4 先说设计目标，再定义 f 与 g

我们寻找位置编码函数 \(f_Q,f_K\)，希望分别给两侧输入添加位置后，内积可以写成只显式使用相对位移的函数 g：

\[ \boxed{f_Q(x_m,m)^{\mathsf T}f_K(x_n,n)=g(x_m,x_n,m-n)}. \tag{A8} \]

这里不是证明 f=g。f 输出向量，g 输出一个实数匹配分数；需要证明的是「两个 f 输出的点积等于 g」。g 仍然依赖两侧内容，并不是一个仅由距离决定的函数。

先取投影后的二维列向量 \(q=W_Qx_m\)、\(k=W_Kx_n\)，对应复数 \(z_q=\mathcal C(q)\)、\(z_k=\mathcal C(k)\)。用带帽符号表示复数形式，避免把实向量与复数直接混写成同一种对象：

\[ \begin{aligned} \widehat f_Q(x_m,m)&=z_qe^{\mathrm{i}m\theta}, &f_Q(x_m,m)&=\mathcal C^{-1}(\widehat f_Q)=R(m\theta)q,\\ \widehat f_K(x_n,n)&=z_ke^{\mathrm{i}n\theta}, &f_K(x_n,n)&=\mathcal C^{-1}(\widehat f_K)=R(n\theta)k. \end{aligned}\tag{A9} \]

这组定义来自正文 2.1 的角度差要求：选取位置线性相位后，相减能留下位移。在这个附录中统一使用 \(\delta=m-n\)，并定义：

\[ g(x_m,x_n,\delta) :=\operatorname{Re}\!\left[z_q\overline{z_k}e^{\mathrm{i}\delta\theta}\right]. \tag{A10} \]

正文采用的是 \(\Delta=n-m=-\delta\)。两种方向都可以，但指数与共轭必须成套使用；下面会把它们对应起来。

A.5 逐行证明：两个 f 的内积就是 g

第一步，用 A7 把实数点积换成复数乘积的实部；第二步代入 A9；第三步对乘积取共轭，指数中的虚部符号反转；第四步合并指数：

\[ \begin{aligned} f_Q(x_m,m)^{\mathsf T}f_K(x_n,n) &=\operatorname{Re}\!\left[\widehat f_Q(x_m,m)\overline{\widehat f_K(x_n,n)}\right]\\ &=\operatorname{Re}\!\left[(z_qe^{\mathrm{i}m\theta})\overline{(z_ke^{\mathrm{i}n\theta})}\right]\\ &=\operatorname{Re}\!\left[z_qe^{\mathrm{i}m\theta}\overline{z_k}e^{-\mathrm{i}n\theta}\right]\\ &=\operatorname{Re}\!\left[z_q\overline{z_k}e^{\mathrm{i}(m-n)\theta}\right]\\ &=g(x_m,x_n,m-n). \end{aligned}\tag{A11} \]

为了确认这不是复数记号制造的巧合，再把 g 展开成实数。令 \(\phi=\delta\theta\)，从 A7 已知 \(z_q\overline{z_k}=(ac+be)+\mathrm{i}(bc-ae)\)，于是：

\[ \begin{aligned} g&=(ac+be)\cos\phi-(bc-ae)\sin\phi\\ &=ac\cos\phi+ae\sin\phi-bc\sin\phi+be\cos\phi\\ &=\begin{pmatrix}a&b\end{pmatrix} \begin{pmatrix}\cos\phi&\sin\phi\\-\sin\phi&\cos\phi\end{pmatrix} \begin{pmatrix}c\\e\end{pmatrix}\\ &=q^{\mathsf T}R(-\phi)k =q^{\mathsf T}R((n-m)\theta)k. \end{aligned}\tag{A12} \]

所以矩阵推导出现 n−m，而「Query 乘 Key 共轭」的复数推导出现 m−n，完全一致：A12 中间的矩阵正是负角度旋转。如果改为 \(\overline{z_q}z_k\)，指数也要改为 n−m；整体互为共轭，实部不变。

用一组数字核对符号：取 \(q=(1,2)^{\mathsf T}\)、\(k=(3,4)^{\mathsf T}\)、\(m=1,n=0,\theta=\pi/2\)。直接旋转与复数计算分别得到：

\[ \begin{aligned} R(\pi/2)q&=(-2,1)^{\mathsf T}, &(-2)\times3+1\times4&=-2,\\ z_q\overline{z_k}&=11+2\mathrm{i}, &\operatorname{Re}[(11+2\mathrm{i})\mathrm{i}]&=\operatorname{Re}(-2+11\mathrm{i})=-2. \end{aligned} \]
恒等式的适用范围。两侧使用一致的固定频率与旋转约定，结论对任意实数内容向量成立，不需要随机性假设。固定 q、k 后共同平移位置不会改变该点积；但真实模型换了上下文，q、k 自身可能变化，因此不能由此推出整个网络对所有位置移动都完全不变。

A.6 从一对通道到整个 head：为什么角度只有 d/2 个

令 \(N=d/2\)，用 r 表示通道对编号，避免与虚数单位混淆。第 r 对包含通道 2r 与 2r+1：

\[ z_{q,r}=q_{2r}+\mathrm{i}q_{2r+1},\quad z_{k,r}=k_{2r}+\mathrm{i}k_{2r+1},\quad \theta_r=b^{-2r/d},\quad r=0,\ldots,N-1. \]

每一对的两个坐标共享同一个角度，不是偶数通道一个频率、奇数通道另一个频率。以 d=8、b=10000 为例：

组 r通道对指数 2r/d频率 θr位置 m 的角度
0(0,1)01m
1(2,3)1/40.10.1m
2(4,5)1/20.010.01m
3(6,7)3/40.0010.001m

把 A11 对所有通道对求和，即得到高维版本：

\[ (R_mq)^{\mathsf T}(R_nk) =\operatorname{Re}\!\left[\sum_{r=0}^{N-1} z_{q,r}\overline{z_{k,r}}e^{\mathrm{i}(m-n)\theta_r}\right] =q^{\mathsf T}R_{n-m}k.\tag{A13} \]

如果输入为 (B,H,L,d)，共享位置表为 (L,)，那么频率为 (d/2,)，角度表为 (L,d/2)。代码中的 positions[:, None] * frequencies[None, :] 通过 (L,1) 与 (1,d/2) 广播得到这个表，再共享给 B、H 两个维度。x[..., 0::2] 的省略号保留所有前导维度，绝不是固定省略三个轴。

与正弦加法位置编码的差别。两者都可以使用多频率 sin/cos。RoPE 的结构性特点是把旋转直接施加到 Q/K，让点积里的显式位置因子严格合并为相对位移，同时保持各向量的长度。正弦加法编码本身也有相对位移性质，但与内容相加、再经过一般投影后，整个匹配分数不自动满足 A13。

附录 B：Abel 变换，从前缀和到远程衰减分析

A13 已经完成 RoPE 相对位置性质的证明。Abel 变换不是再加一层编码，也不是实现时要执行的步骤；它把同一个复数求和改写成另一种形式，以便分析频率抵消如何影响分数的上界。

B.1 把「内容系数」与「位置相位」分别命名

延续附录 A 的方向约定，固定当前这对 q、k，令：

\[ \delta=m-n,\quad h_r=z_{q,r}\overline{z_{k,r}},\quad a_r(\delta)=e^{\mathrm{i}\delta\theta_r},\quad Z(\delta)=\sum_{r=0}^{N-1}h_ra_r(\delta).\tag{B1} \]

这里 Z 是复数求和结果，真正的未缩放注意力分数是 \(\operatorname{Re}Z\)。特意不用 T 表示总和，以免和转置上标混淆。r 遍历的是通道对，不是 token 位置；这一点决定了后面的前缀和究竟沿哪个轴计算。

符号含义依赖什么
hᵣ一对通道的复数内容系数Query 与 Key 的实际数值
aᵣ长度为 1 的相位因子相对位移与该组频率
Sⱼ前 j 个相位因子的和频率之间的方向叠加或抵消

B.2 前缀和：先看清 S 的下标

\[ S_0=0,\qquad S_j=\sum_{r=0}^{j-1}a_r,\quad 1\le j\le N. \tag{B2} \]

以 N=3 为例，前缀和与原始项的关系如下。S 的下标表示「已经加了几项」，不是最后一项的索引：

\[ \begin{aligned} S_0&=0, & a_0&=S_1-S_0,\\ S_1&=a_0, & a_1&=S_2-S_1,\\ S_2&=a_0+a_1, & a_2&=S_3-S_2,\\ S_3&=a_0+a_1+a_2. && \end{aligned} \]

因此，任意一项都可以替换成相邻两个前缀和的差：\(a_r=S_{r+1}-S_r\)。Abel 变换的第一步只有这个替换，没有用到近似。

B.3 三项展开：每一个负号从哪里来

① 代入前缀和之差。

\[ \begin{aligned} Z&=h_0a_0+h_1a_1+h_2a_2\\ &=h_0(S_1-S_0)+h_1(S_2-S_1)+h_2(S_3-S_2). \end{aligned}\tag{B3} \]

② 去掉括号。每个括号贡献一个正项和一个负项；由于 S₀=0，只有 h₀S₀ 消失。

\[ \begin{aligned} Z&=h_0S_1-h_0S_0+h_1S_2-h_1S_1+h_2S_3-h_2S_2\\ &=h_0S_1+h_1S_2-h_1S_1+h_2S_3-h_2S_2. \end{aligned} \]

③ 按相同的 S 合并。把含 S₁ 的项放在一起，接着是 S₂，最后保留边界项 S₃h₂。

\[ \begin{aligned} Z&=(h_0S_1-h_1S_1)+(h_1S_2-h_2S_2)+h_2S_3\\ &=S_1(h_0-h_1)+S_2(h_1-h_2)+S_3h_2. \end{aligned}\tag{B4} \]

④ 补一个零，让边界写法统一。原来只有 h₀、h₁、h₂，现在额外定义 h₃=0，于是 h₂=h₂−h₃：

\[ Z=S_1(h_0-h_1)+S_2(h_1-h_2)+S_3(h_2-h_3). \]

⑤ 若希望差分写成「后项减前项」，就在整体前面补负号。

\[ Z=-\left[S_1(h_1-h_0)+S_2(h_2-h_1)+S_3(h_3-h_2)\right]. \tag{B5} \]
h₃=0 不是让最后一对通道归零。真实内容项最后一个是 h₂。新增 h₃ 只用于表达边界。即使真实 h₀=h₁=h₂，最后的差 h₃−h₂ 仍然不为零，不能漏掉它，否则会错误地把整个和算成零。

B.4 任意 N 项：显式保留边界，再压缩记号

将两组求和拆开，第二组把索引从 r 换成 j，再把重叠范围对齐：

\[ \begin{aligned} Z&=\sum_{r=0}^{N-1}h_r(S_{r+1}-S_r)\\ &=\sum_{j=1}^{N}h_{j-1}S_j-\sum_{j=0}^{N-1}h_jS_j\\ &=h_{N-1}S_N-h_0S_0+\sum_{j=1}^{N-1}S_j(h_{j-1}-h_j)\\ &=h_{N-1}S_N+\sum_{j=1}^{N-1}S_j(h_{j-1}-h_j). \end{aligned}\tag{B6} \]

额外定义 \(h_N=0\)，其中 N 是通道对总数，就可以把边界并入求和：

\[ \boxed{Z=\sum_{r=0}^{N-1}S_{r+1}(h_r-h_{r+1}) =-\sum_{r=0}^{N-1}S_{r+1}(h_{r+1}-h_r)},\qquad h_N=0. \tag{B7} \]

这就是这里使用的 Abel 变换，也叫离散分部求和。它把「内容系数乘原始相位项」改写为「相位前缀和乘内容差分」。实数、复数都满足这里的分配律，所以没有因复数而增加额外假设。

用普通数字检验下标：取 a=(2,3,5)、h=(4,6,8)，则 S=(0,2,5,10)，并补 h₃=0。这里的 a 只是代数核对，不要求它们是 RoPE 的单位复数：

\[ \begin{aligned} Z_{\mathrm{original}}&=4\times2+6\times3+8\times5=66,\\ Z_{\mathrm{Abel}}&=2(4-6)+5(6-8)+10(8-0)\\ &=-4-10+80=66. \end{aligned} \]

B.5 从恒等式到上界：每一步用什么不等式

到 B7 为止，全部是严格相等。接下来才开始估计大小：实部绝对值不超过复数的模；和的模不超过各项模的和；乘积的模等于模的乘积。

\[ \begin{aligned} |\operatorname{Re}Z| &\le |Z|\\ &=\left|\sum_{r=0}^{N-1}S_{r+1}(h_r-h_{r+1})\right|\\ &\le\sum_{r=0}^{N-1}|S_{r+1}|\,|h_r-h_{r+1}|. \end{aligned}\tag{B8} \]

把所有内容差分统一放大为最大值，可得到正文第四章使用的上界。定义最大差分 C 与平均前缀和模长 A：

\[ C=\max_{0\le r<N}|h_{r+1}-h_r|,\qquad A(\delta)=\frac1N\sum_{j=1}^{N}|S_j(\delta)|. \]
\[ \boxed{|\operatorname{Re}Z(\delta)|\le CN A(\delta)},\qquad \left|\frac{\operatorname{Re}Z(\delta)}{\sqrt d}\right| \le\frac{CN}{\sqrt d}A(\delta).\tag{B9} \]

也可以提取最大的前缀和，保留内容差分之和，得到另一种同样正确的界：

\[ |\operatorname{Re}Z| \le\left(\max_{1\le j\le N}|S_j|\right) \sum_{r=0}^{N-1}|h_{r+1}-h_r|.\tag{B10} \]

两种界强调的对象不同，不能把其中的最大值、求和与平均值随意互换。原论文图中考察的频率量对应 A，而不是 B10 中的最大前缀和。正文与本附录的相位符号相反，S 互为共轭，模长完全相同，因此上界分析一致。

B.6 能推出什么，不能推出什么

每个 aᵣ 都是复平面上长度为 1 的箭头。当 δ=0 时，它们全部朝向实轴正方向，所以 Sⱼ=j；当 δ 改变，不同频率的箭头可能错开方向，前缀和中就可能出现抵消。这使 A 成为研究频率组合的一个合理量。

\[ A(0)=\frac1N\sum_{j=1}^{N}j=\frac{N+1}{2}. \]

但三角不等式没有证明 A 随距离单调下降，更没有证明实际 attention 权重必然衰减。有限频率会振荡，内容系数会变化，softmax 还会引入同一行其他 key 的竞争。即便一个上界在某段距离上下降，也只限制实际值的可能范围，不保证实际值本身随之单调下降。

结论性质前提或限制
RoPE 点积显式依赖相对位移严格恒等式Q/K 使用一致的固定频率与旋转规则；内容仍参与计算
Abel 改写与 B8～B10 上界严格代数与不等式保留边界项；比较频率作用时固定内容系数
论文频率量的远程变化趋势给定频率、维度、距离范围的数值分析不是任意内容的 attention 权重曲线
长上下文质量更好需要模型实验评估取决于训练分布、频率设计、任务与缓存位置对齐
把证明与直觉分开，才能正确使用结论。旋转与复数解释相对位移为什么严格出现；Abel 变换帮助把频率抵消与内容变化分离；距离偏置与长度泛化则还需要数值分析和训练证据。RoPE 提供位置结构，不强制模型把远处的重要信息判成不相关。
RoPE 把每个 token 的绝对位置变成旋转角度，再利用点积中的逆旋转，把两个角度化成相对位移。二维旋转解释了相对位置，多频率解释了尺度，缓存对齐解释了工程约束。真正值得记住的是这条推导链：位置的差值结构 → 旋转的复合规律 → Q/K 的相对匹配；而远程衰减与长度外推，都必须在这条恒等式之外继续讨论内容与训练分布。
