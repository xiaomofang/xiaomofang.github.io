交叉熵是什么：从信息量、凸优化到 LM Loss

交叉熵量的是：用你猜的概率去编码真实发生的事，平均要花多少。 本文先把概率公式手算清楚，再展开原文中的关键推导与直觉 《除了交叉熵，LM Loss还有什么选择？》 里多数人卡住的三块：恰当评分、logits 上的凸性、Fenchel–Young / 信息几何直觉。 不预设凸优化或信息几何背景。

一、交叉熵从哪来

先忘掉神经网络。一件事发生了，它有多「意外」？越稀有，说出来越费信息：

\[ I(x)=-\log p(x) \]

\(p=0.5\) 时 \(I=-\ln 0.5\approx 0.693\)；\(p=0.05\) 时 \(I\approx 2.996\)。 训练里常用自然对数，单位是 nat（\(\log_2\) 则是 bit，只差常数倍）。

世界按 \(p\) 出牌，平均意外程度是熵：

\[ H(p)=-\sum_x p(x)\log p(x) \]

直觉上：每个 \(x\) 的意外程度是 \(-\log p(x)\)，再按它真正出现的频率 \(p(x)\) 加权平均。 若某件事几乎必然发生（\(p\approx 1\)），熵接近 0——没什么好「惊讶」的； 若许多结果差不多均匀（词表上每个词都差不多可能），熵就大——下一词本来就更难猜。

为什么要盯 \(H(p)\)？ 它不是训练目标本身，而是交叉熵的理论下界：再怎么训，CE 也不能低于 \(H(p)\)。 数据越「乱」、下一词越不确定，\(H(p)\) 越高，loss 地板就抬得越高——所以看到 CE 降不动时，先问一句：是模型还没学好，还是数据本身熵就很大。

模型给不出真 \(p\)，只能猜一份 \(q\)。真实世界仍按 \(p\) 出现各个 \(x\)，你却用 \(-\log q(x)\) 去计量「花了多少」。 平均花销就是交叉熵：

\[ \mathrm{CE}(p,q)=-\sum_x p(x)\log q(x) \]

「交叉」：权重来自真分布 \(p\)，对数里却是猜测 \(q\)。 上下两条公式不是两套定义——下面是上面恒等变形拆出来的：在 \(\log q\) 里插入 \(\log p\)：

\[ \begin{aligned} \mathrm{CE}(p,q) &= -\sum_x p(x)\log q(x) \\ &= -\sum_x p(x)\bigl(\log p(x)+\log\tfrac{q(x)}{p(x)}\bigr) \\ &= \underbrace{-\sum_x p(x)\log p(x)}_{H(p)} \;+\; \underbrace{\sum_x p(x)\log\frac{p(x)}{q(x)}}_{D_{\mathrm{KL}}(p\|q)} \end{aligned} \]

所以写成：

\[ \mathrm{CE}(p,q)=H(p)+D_{\mathrm{KL}}(p\|q),\qquad D_{\mathrm{KL}}(p\|q)=\sum_x p(x)\log\frac{p(x)}{q(x)}\ge 0 \]

KL \(\ge 0\)（Gibbs 不等式），等号当且仅当 \(p=q\)。 因此 \(H(p)\) 对固定数据是常数：最小化 CE ≡ 最小化 KL ≡ 让 \(q\) 去贴 \(p\)。 \(q=p\) 时橙色为零，CE 降到下界 \(H(p)\)。

上图蓝色块旁写的「最短平均码长」，是把熵换成压缩 / 通信语言来说同一件事。 这里的码长：给每个可能出现的符号 \(x\) 编一串码（例如一串 0/1），这串有多长，就叫该符号的码长； 平均码长 = 按真实频率 \(p(x)\) 对各个码长取期望——传一条消息平均要花多少比特（或 nat）。 常见的例子：Zip 压缩、哈夫曼编码——越常出现的符号，码应越短。

香农定理说：若你事先知道真分布 \(p\)，并按 \(p\) 来设计码本（给 \(x\) 大约 \(-\log p(x)\) 那么长的码）， 平均码长最低可以逼近 \(H(p)\)，再短就不行了——这就是图里蓝色底座。 「与模型无关」的意思是：这块下界只由数据 \(p\) 决定；神经网络猜的是 \(q\)，再差也动不了蓝色，只能把橙色 KL 压小。 若你不知道 \(p\)、只好按猜的 \(q\) 来编，平均码长就变成交叉熵 \(\mathrm{CE}(p,q)\)，比 \(H(p)\) 多出来的正是橙色。

二、概率视角：它就是最大似然

把「下一个词」看成词表上的分类。一次观测到真词 \(y\)，模型给出 \(q(y)\)，这条样本的似然就是 \(q(y)\)。 \(N\) 条独立样本的对数似然是

\[ \ell=\sum_{n=1}^{N}\log q(y_n) \quad\Longleftrightarrow\quad -\frac{1}{N}\ell=\frac{1}{N}\sum_{n=1}^{N}-\log q(y_n) \]

右边正是硬标签交叉熵。最大化似然 = 最小化 CE。若把 \(N\) 次采样看成对未知 \(p\) 的经验分布 \(\hat p\)， 这也是 \(\mathrm{CE}(\hat p,q)\)。

Softmax 从哪来？语言模型最后一层（LM head）对词表每个词输出一个实数 \(z_i\)，叫 logit。 这里的「无界分数」指：\(z_i\) 可以是任意实数——可正可负、可很大可很小，不必落在 \([0,1]\)，也不必加起来等于 1。 它只表示「模型觉得这个词有多强」的相对打分，还不是概率。

但交叉熵 / 似然要的是概率 \(q\)：\(q_i>0\) 且 \(\sum_i q_i=1\)。 所以要把无界的 \(z\) 压成合法分布，最常用的就是 Softmax（指数族 / Gibbs 分布）：

\[ q_i=\frac{e^{z_i}}{\sum_j e^{z_j}} \]

指数 \(e^{z_i}\) 先把任意实数变成正数，再除以总和做归一化——于是 \(q_i>0\) 且 \(\sum q_i=1\)。 \(z_i\) 越大，对应词的概率越高；\(z\) 整体加减同一个常数，\(q\) 不变（只比相对高低）。 后文会看到：若你希望损失对 \(z\) 的梯度等于 \(q-e_y\)，反推出来的激活恰好就是它。

三、手算一遍

词表：{cats, dogs, to, eat, pizza}。教师（或真实）分布 \(p=(0.52,0.19,0.09,0.07,0.05)\)，学生 \(q=(0.45,0.25,0.15,0.10,0.05)\)。逐项：

每一项都是「这个词有多常发生 × 模型觉得它有多意外」。真词被模型压得很低时，\(-\ln q\) 会很大，这一项把总损失拉高。 （上表用 \(\ln\)；有的教材用 \(\log_2\)，数值差 \(\ln 2\)，排序不变。）

3.1 先分清两件事：硬标签 vs 软蒸馏

交叉熵公式 \(\mathrm{CE}(p,q)=-\sum p\log q\) 里，模型侧永远是 \(q\)；差别只在标签 \(p\) 长什么样。 实务上常见两种喂法：

  • 硬标签（hard label）：语料只告诉你「下一个词是哪个」——比如这次答案是 cats。 标签是尖峰：真词概率 = 1，其余 = 0。这就是 one-hot（独热编码）：一整行里只有一格是 1，其它全是 0。 注意：不是「整个训练只用一个样本」（那是 one-shot 学习，另一回事）；而是每一条样本各自一个 one-hot。
  • 软蒸馏（soft distillation）：标签不是尖峰，而是教师模型吐出的整份概率山——cats 0.52、dogs 0.19… 学生要学的是「整座山长得像不像老师」，不是只盯住一个词。

各自用来做什么？ 硬标签是预训练 / SFT 的默认：语料天然就是「上下文 → 下一个真词」，便宜、好造。 软蒸馏用在知识蒸馏、投机解码草稿器对齐目标模型等场景：你有一个更强的教师（或目标 LM），希望学生不只猜对 argmax，还学到「第二名、第三名有多像」。

3.2 硬标签：一条样本一个 one-hot，再批量平均

一条训练样本进来，真词是 \(y\)（比如 cats）。把 \(p\) 换成 one-hot \(e_y=(1,0,0,\ldots)\)， 交叉熵求和只剩真词那一项：

\[ \mathrm{CE}(e_y,q)=-\log q_y \]

若 \(y=\text{cats}\)、\(q_y=0.45\)，则 \(-\ln 0.45\approx 0.799\)。 其它词不直接出现在这一行里，但会通过 Softmax 分母分走真词的概率——你把 dogs 抬高，cats 的 \(q_y\) 就会掉，loss 仍会涨。 \(q_y=0.90\) 时约 \(0.105\)；\(q_y=0.05\) 时约 \(3.00\)。连续可反传，不是 0/1 对错记分。

一条算完就完了吗？不是。 训练是「一个个算，再聚合」：

  1. 样本 1：「白切」→ 鸡，算 \(-\log q(\text{鸡})\)
  2. 样本 2：「白切」→ 鸭，算 \(-\log q(\text{鸭})\)
  3. 样本 3、4、… 同理
  4. 一个 batch / 整个 epoch 里把这些数平均（或求和再除以 \(N\)），得到这一步的 loss，再反传

所以：单条 = 一个 one-hot → 一项 \(-\log q_y\)；多条 = 多次这样算，再平均。 平均得多了，就在用采样逼近「若把所有可能下一词的真实频率摊开」时的完整 \(\mathrm{CE}(p,q)\)。

3.3 软蒸馏：一次对齐整座山

教师若能给出整份 \(p\)（例如目标模型同位置的 Softmax），公式仍是 \(\mathrm{CE}(p,q)=-\sum_v p(v)\log q(v)\)——就是第三节开头那张表整行加总，不再压成尖峰。 一条样本里，cats、dogs、to… 每一格都进 loss：教师觉得可能的词，学生也要分到相近的概率。

硬 / 软是同一条交叉熵：硬是「每次只看见一个采样词」的蒙特卡洛版；软是「标签已是完整分布」的显式期望版。 实务上按任务二选一；两边算出的数字也不可直接比大小——因为标签 \(p\) 不同，下界 \(H(p)\) 就不同（硬标签 one-hot 的熵是 0，软标签熵通常 > 0）。

四、LM Loss 为什么几乎只能是交叉熵

《除了交叉熵，LM Loss还有什么选择？》 （2026-08-09）的出发点不是再背一遍公式，而是：交叉熵看起来理所当然，能不能换？换了要满足什么？ 下面按三条线展开，补上凸优化和信息几何里缺的直觉。

4.1 恰当评分：损失必须能对「一次采样」打分

图像分类常是一对一；语言是一对多——「白切」后面可以是鸡、鸭、狗、羊。要学的是整份条件分布。 可训练时语料是零散送来的：这次「白切鸡」，下次「白切鸭」，事先没有完整频率表。

因此损失必须对目标分布 \(p\) 线性，才能写成「只看见一个采样 token \(i\)，打一个分 \(S(q,i)\)，再求期望」：

\[ L(p,q)=\sum_i p_i\,S(q,i)=\mathbb{E}_{i\sim p}\bigl[S(q,i)\bigr], \quad p=\arg\min_q L(p,q) \]

这就是恰当评分规则（Proper Scoring Rules）：诚实报出真分布时，期望分数最好。 Total Variation \(\sum|p_i-q_i|\) 虽然直观，改写成采样形式时会出现 \(q_i/p_i\)，而 \(p_i\) 你并不知道——所以它当不了 LM Loss。

可得：固定 \(p\) 时 \(L\) 的最小值是 \(H(p)=L(p,p)\)；\(L\) 对 \(p\) 又是线性的，于是 \(L(\,\cdot\,,q)\) 必须是凹函数 \(H\) 在 \(q\) 处的切平面。 任选一个凹的 \(H\)，就能造出一套评分。对数评分对应 \(H(p)=-\sum p_i\log p_i\)，切出来正好是 \(S(q,i)=-\log q_i\)。

唯一性。 若再要求 \(S(q,i)\) 只依赖真类概率 \(q_i\)（不显式看其它类），恰当评分里本质上只剩下 \(-\log q_i\)。 这不是习惯，是结构。Brier / Tsallis / 球面 / Rényi 都是合法推广，但它们的 \(S\) 会看见整份 \(q\)；\(\alpha\to 1\) 时都退回交叉熵。

对数 / 交叉熵香农熵只看 \(q_i\)
Brier（平方）\(1-\|p\|_2^2\)整份 \(q\) 到 one-hot 的平方距离
Tsallis / 球面 / Rényi带 \(\alpha\) 的广义熵整份 \(q\) 的 \(\alpha\) 次方结构

4.2 凸优化：在 logits 上看，CE 是「干净的碗」

网络最后一层给出 \(z\in\mathbb{R}^{|V|}\)，再 Softmax 成 \(q\)。我们真正拿去给 Adam 的，是 \(L\) 对 \(z\) 的梯度。 Softmax + 硬标签 CE 有著名结论：

\[ \nabla_z\bigl(-\log q_y\bigr)=q-e_y \]

含义直白：把真类概率往上抬，把其它类往下压；偏差多大，梯度就多大。只有 \(q=e_y\) 时梯度为零。

再看 Hessian。Softmax 的雅可比是 \(\mathrm{diag}(q)-qq^\top\)（半正定），CE 对 \(z\) 的二阶导就是它。 所以 \(-\log q_y\) 作为 \(z\) 的函数是凸的：碗只有一个底，任意点的梯度都指向 \(e_y\) 那一侧。

Brier（平方损失）配 Softmax 时，梯度多乘一项同一个雅可比：

\[ \nabla_z\|q-e_y\|_2^2=2\bigl(\mathrm{diag}(q)-qq^\top\bigr)(q-e_y) \]

若模型「自信地错了」——\(q\) 几乎是另一个 one-hot \(e_j\neq e_y\)——括号里的矩阵在这个顶点附近接近零，梯度消失。 前中期大部分预测都不准，平方损失学得很慢；后期那些死磕错答案的样本，它反而可能跳过（有时对噪声更稳）。 因此：CE 更适合作为主损失；平方损失最多在后期作为辅。

4.3 信息几何直觉：单纯形上的对偶，不是玄学

不必先去读信息几何教材。需要的画面只有一张：所有词表分布住在概率单纯形 \(\Delta=\{q:q_i\ge 0,\sum q_i=1\}\) 上——三维时就是一个三角形，顶点是各个 one-hot。

KL 不是欧氏距离：它不对称，\(D_{\mathrm{KL}}(p\|q)\neq D_{\mathrm{KL}}(q\|p)\)。 它是负熵 \(\psi(q)=\sum q_i\log q_i\) 生成的 Bregman 散度：

\[ D_\psi(p\|q)=\psi(p)-\psi(q)-\langle\nabla\psi(q),\,p-q\rangle \]

几何直觉：用 \(q\) 处的切平面去近似凹/凸函数 \(\psi\)，点和切面的竖直差距就是「散度」。 交叉熵里多出来的 KL，正是这份差距。欧氏平方距离是 \(\psi(x)=\frac12\|x\|^2\) 生成的 Bregman——所以 Brier 是另一套几何，不是同一把尺子。

后半部分用 Fenchel–Young 把「评分」和「激活」锁定为一对对偶。人话版：

  • 你希望 \(\nabla_z S(q,i)=q-e_i\)（梯度干净）。
  • 这迫使存在一个凸函数 \(\Phi(z)\)，使得 \(q=\nabla\Phi(z)\)，且 \(\Phi\) 是 \(-H\) 的凸共轭：\(\Phi(z)=\max_p\,p\cdot z+H(p)\)。
  • 取香农熵时，这个 \(\max\) 的解就是 Softmax，\(\Phi(z)=\mathrm{LogSumExp}(z)\)。
  • 换一套 \(H\)（Tsallis 等），对偶激活就变成 Sparsemax / Entmax-\(\alpha\)：可以输出精确的零，分布更稀疏。

所以 Softmax 和 CE 几乎总成对出现：一个是另一个的凸对偶。换损失往往还得换激活，预训练默认不动，原因在这里。

五、落到 PyTorch

CrossEntropyLoss 吃 logits + 类别下标，内部做 log-softmax，对应 \(-\log q_y\)： 

import torch
import torch.nn.functional as F

logits = torch.tensor([[2.0, 1.2, 0.5, 0.1, -0.3]])
hard = F.cross_entropy(logits, torch.tensor([0]))  # 硬标签

p = torch.tensor([[0.52, 0.19, 0.09, 0.07, 0.05]])
soft = -(p * F.log_softmax(logits, dim=-1)).sum(-1).mean()  # 软 CE(p, q)
已经 softmax 过的概率，不要再丢进默认 CrossEntropyLoss。 软标签用手写 \(-\sum p\log q\)，或 kl_div(log_softmax(logits), p)（它吃 log-prob）。

六、再回到 EAGLE

EAGLE-3 的 token 损失就是上面的 CE（硬或软看脚本）。TTT 模拟约 5 步，不是把 5 个位置拼成一条再算， 而是每步各自一份 \(q\)、各自一次 CE，再求和。接受率是推理指标，不是这个 sum。

交叉熵先是「用错码本要多花多少」；硬标签是采样版，软蒸馏是整座山。 归结起来：要能对一次采样打分、要在 logits 上凸、要梯度干净——对偶回来几乎只能得到 Softmax + CE。
